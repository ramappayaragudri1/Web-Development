🛍️ **Men’s Fashion E-Commerce Platform (E-Shop)**

Developed a responsive multi-page e-commerce web application focused on premium men’s fashion and lifestyle products. The platform provides an end-to-end shopping experience, including product discovery, search and filtering, dynamic cart management, direct ordering, user authentication, customer feedback, and order history.

### 🌟 Key Features

🛒 **Product & Shopping Experience**
• Featured fashion collection with jackets, shirts, watches, footwear, and coats
• Real-time product search and client-side filtering
• Product cards with images, prices, and ratings
• Product Quick View modal for detailed information
• Dynamic shopping cart with quantity increase/decrease and item removal
• Automatic subtotal and order total calculation
• Direct “Order Now” option for individual products
• Persistent cart data using browser localStorage

📦 **Order Management**
• Checkout/order forms with customer and shipping information
• Automatic order record generation
• Order history with order ID, date, customer details, items, and shipping address
• Order data preserved across browser sessions using localStorage

🔐 **Authentication & Session Management**
• Login and registration interface
• Client-side form validation
• User account information stored using localStorage
• Login session tracking using `isLoggedIn` state
• Logout functionality with session clearing and redirect

💬 **Customer Feedback**
• Contact and inquiry form
• Interactive 5-star rating system
• Rating sentiment labels
• Persistent feedback history
• Quick feedback modal accessible throughout the website

📱 **Responsive Design**
Designed for desktop, tablet, and mobile devices using **CSS Flexbox, CSS Grid, Bootstrap 5, and responsive layouts**. Navigation, product grids, cart interfaces, forms, and modals adapt to different screen sizes.

### 🏗️ Technical Implementation

The application is built using a modular multi-page structure with separate HTML, CSS, and JavaScript files for different sections.

**HTML5** provides the page structure and semantic elements.
**CSS3** handles layouts, animations, responsive design, product cards, modals, and custom styling.
**Bootstrap 5.3** provides responsive components and UI utilities.
**Vanilla JavaScript (ES6+)** manages product rendering, search, filtering, cart operations, order processing, authentication, validation, ratings, and local data management.
**Web Storage API** provides client-side persistence for cart items, users, login state, feedback, and order history.

### 💾 Client-Side Data Management

The project uses browser `localStorage` to maintain application state, including:

• Cart items and quantities
• Registered user information
• Login status
• Completed orders
• Customer feedback and ratings

This allows users to retain their shopping data and order history even after refreshing or reopening the browser.
